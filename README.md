# BookNook

BookNook is an online library for discovering, sharing, borrowing, and returning books.

**Live Website:** [Visit BookNook](https://booknook-client-nine-rouge.vercel.app/)

## Features

- Email/password and Google login with Better Auth.
- Browse books and view detailed information.
- Add, edit, and delete your own books.
- Borrow and return books with copy availability tracking and duplicate-borrow prevention.
- Responsive design with light and dark themes.
